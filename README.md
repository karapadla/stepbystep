# Step by Step: автономний додаток

## Опублікувати безкоштовно (GitHub Pages)
1. Зареєструйся на github.com і створи новий публічний репозиторій, наприклад `step-by-step`.
2. Натисни «Add file → Upload files» і завантаж УСІ файли з цієї папки (не zip).
3. Settings → Pages → Source: «Deploy from a branch», гілка `main`, папка `/ (root)` → Save.
4. Через 1–2 хвилини адреса буде такою: `https://ТВІЙ-НІК.github.io/step-by-step/`. Її й надсилай друзям.

Є альтернатива без реєстрації: перетягни папку на https://app.netlify.com/drop.

## Встановити на телефон
- iPhone (Safari): «Поділитись → На початковий екран».
- Android (Chrome): меню ⋮ → «Установити застосунок».

## Важливо
- Дані зберігаються тільки на пристрої. Для переносу або резервної копії є «Зберегти» й «Відновити» в ⚙.
- Хмарної синхронізації та ШІ-функцій тут немає: вони працюють лише всередині Claude.
- Оновлюючи `index.html`, змінюй номер `sbs-v1` у `sw.js` (наприклад, на `sbs-v2`), щоб у друзів з'явилась нова версія.

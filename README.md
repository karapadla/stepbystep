# Step by Step: трекер звичок («звички як маршрути»)

PWA без збірки: чистий JS, CSS окремим файлом, дані тільки на пристрої (`localStorage`).
Сайт: https://karapadla.github.io/stepbystep/

## Структура
```
index.html            розмітка + підключення css/js
sw.js                 service worker (версія кешу + список файлів)
manifest.webmanifest  PWA-маніфест
icon-*.png, apple-touch-icon.png
css/style.css         усі стилі
js/                   логіка (класичні скрипти, спільний глобальний простір)
```
Файли в `js/` підключаються в `index.html` у фіксованому порядку: core, habits, modals, workouts-books, diary, sound-reminders, sudoku-meditation, overlays-stats, icons-awards, sync-data, calendar-events, journeys, main. Код, що виконується під час завантаження, може посилатися лише на функції з того ж або раніших файлів. `main.js` має лишатися останнім.

## Опублікувати (GitHub Pages)
1. Репозиторій: `karapadla/stepbystep`.
2. «Add file → Upload files»: завантажити змінені файли разом із папками `css/` і `js/` (не zip).
3. Settings → Pages → Source: «Deploy from a branch», гілка `main`, папка `/ (root)`.
4. Через 1–2 хвилини зміни з'являться на сайті.

## Встановити на телефон
- iPhone (Safari): «Поділитись → На початковий екран».
- Android (Chrome): меню ⋮ → «Установити застосунок».

## Оновлення й кеш
- Після зміни будь-якого файлу, який кешується, підвищ версію в `sw.js` (змінна `C`, зараз `sbs-v8`), інакше телефон покаже стару версію.
- Новий файл JS або CSS додай і в `index.html`, і в список `F` у `sw.js`.
- Після оновлення на телефоні повністю закрий додаток і відкрий знову.

## Дані
- Усе зберігається на пристрої в `localStorage`, ключ `tracker-v1`. Ключ і структуру даних змінювати лише разом із міграцією (див. `init()` у `js/core.js`).
- Резервна копія й перенесення: «Зберегти» та «Відновити» в ⚙.
- Хмарної синхронізації й ШІ-функцій на GitHub Pages немає: ці виклики працюють лише всередині Claude.

## Можливості
- Вкладки: Шляхи, Звички, Вправи, Читання, Щоденник, Огляд (порядок можна змінювати перетягуванням).
- Звички: періодичність, пропуски, стріки, річна сітка активності, архів.
- Шляхи (Journeys): режими Окремий, Об'єднаний, Змішаний, Самурай; контрольні точки, пауза, відновлення, завершення. Шлях лише візуалізує прогрес звички.
- Вправи з цілями, рекордами й таймером відпочинку; Читання з книгами, оцінками й коментарями.
- Щоденник з настроями, тегами й цитатами; Огляд зі статистикою.
- Судоку, Медитація, досягнення й челенджі, нагадування, експорт `.ics`.
- Світла й темна теми (Premium Minimalism).

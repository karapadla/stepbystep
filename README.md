# Step by Step

PWA-трекер звичок: «звички як маршрути». Інтерфейс українською. Чистий JavaScript, без фреймворків і збірки. Дані зберігаються лише на вашому пристрої (`localStorage`).

Сайт: https://karapadla.github.io/stepbystep/

## Можливості
- **Шляхи**: маршрути зі звичок, режими Окремий, Об'єднаний, Змішаний, Самурай; контрольні точки.
- **Звички**: періодичність, пропуски, серії, річна сітка, архів.
- **Вправи**, **Читання** (книги, оцінки, коментарі, пошук книг за назвою або ISBN), **Щоденник** (настрої, теги, цитати).
- **Огляд**: тиждень, місяць, рік; метрики, діаграми, нагороди та виклик тижня.
- Судоку, медитація.
- Світла й темна теми, офлайн-режим, вібровідгук (Android і iPhone з iOS 17.4+).

## Запуск і встановлення
Відкрийте сайт у браузері телефона й виберіть «Додати на головний екран». Локально: `python3 -m http.server`, далі http://localhost:8000 (service worker не працює з `file://`).

## Резервна копія
⚙ → «Зберегти» створює файл з усіма даними, «Відновити» повертає їх. Робіть копію перед очищенням браузера.

## Структура
```
index.html, sw.js, manifest.webmanifest, іконки (png)
css/style.css
js/core.js  habits.js  modals.js  workouts-books.js  diary.js  sound-reminders.js
js/sudoku-meditation.js  overlays-stats.js  icons-awards.js  sync-data.js
js/calendar-events.js  journeys.js  main.js
```
Усі `js/*.js` це класичні скрипти в одному глобальному просторі. Порядок підключення в `index.html` фіксований, `main.js` завжди останній. Докладніше в `PROJECT_STATE.md`.

## Оновлення
1. Змініть файли та **підніміть версію кешу** `C` у `sw.js` (зараз `sbs-v11`).
2. Завантажте файли на GitHub (гілка `main`).
3. На телефоні повністю закрийте й знову відкрийте додаток.

## Приватність
Усі дані лишаються на пристрої. Єдині зовнішні запити: шрифти Google Fonts і пошук книг (Open Library та Google Books отримують текст запиту або ISBN). Вібровідгук можна вимкнути: `localStorage.setItem('sbs-vib','0')`.
